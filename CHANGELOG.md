# Changelog

## 1.0.0

First release.

- Memories per workspace: remember, recall (BM25 with trust and recency), confirm, dispute, expiry, a size limit that
  archives the least useful entries, and a guard that refuses credentials.
- Claims on files, folders and named resources: exclusive or shared, per project, renewable, released when the task
  ends or the claim expires.
- Work log and file history.
- Briefing tool that combines pinned memories, relevant conventions, other agents' claims and recent work.
- Team-board decisions become memories.
- Read-only page with counters and tabs for memories, claims, activity and tasks.
- HTTP API for listing, searching, editing, pinning, archiving, deleting, export and import.
